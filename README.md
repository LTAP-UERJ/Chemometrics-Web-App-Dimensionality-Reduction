## 🚀 Key Features

### **1. Data Adequacy & Homogeneity**
* **Adequacy Tests:** Bartlett’s Sphericity and Kaiser–Meyer–Olkin (KMO) index.
* **Homogeneity Tests:** Chi-squared, Fligner-Killeen, Levene, and Bartlett tests.

### **2. Outlier Detection**
* Univariate tests: Dixon, Grubbs, and Rosner tests.
* Multivariate analysis based on Chi-squared distribution.

### **3. Spectral Resolution & Filtering**
* Low Variance and High Covariance filters.
* **Wavelet Transform** for advanced data compression and noise reduction.

### **4. Cluster Analysis**
* Optimization: Analysis of the optimal number of clusters.
* Methods: **HCA** (Hierarchical Cluster Analysis) and **K-Means**.
* Visualization: Interactive Correlation Heatmaps.

### **5. Exploratory Analysis**
* **Parametric Methods:** PCA (Principal Component Analysis), Robust PCA, Factor Analysis, and ICA (Independent Component Analysis).
* **Non-Parametric Methods:** Kernel PCA, t-SNE, MDS (Multidimensional Scaling), and Isomap.
